# Проверка требований Advanced v2.0

Проверка текущего кода, автоматических тестов и опубликованного браузерного конвейера. Статусы ниже разделяют наличие работающей функции, её ограничения и проверки на физических устройствах. Предыдущая версия не выполняла все рекомендации полностью.

## 19.1. Базовые функции

| Требование         | Статус                             | Фактическая реализация                                                                                                                                                                                                            |
| ------------------ | ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Metadata Cleaner   | Реализован для MP4; WebM ограничен | После кодирования удаляются необязательные MP4-блоки и имя кодировщика. Размеры атомов и смещения потоков сохраняются. Для WebM используются флаги кодировщика и отчёт об оставшихся полях, отдельной финальной очистки WebM нет. |
| Duration Variation | Реализовано                        | ±0,2–0,9 с, с округлением по FPS. Совместно с кадрами выбирается пересечение диапазонов. Удлинение — замороженный хвост и тишина; это не незаметное продолжение движения.                                                         |
| Frame Variation    | Реализовано с ограничением         | 6–27 кадров, стандартно 9–18. Нормализованные FPS и скорость учитываются в базе сравнения. Число кадров результата проверяется декодированием. Замороженный хвост может быть заметен.                                             |
| Pixel Variation    | Реализовано                        | Реальные фильтры яркости, оттенка, зерна и другие визуальные изменения. 7–8/255 обозначено как ориентир; автоматической подгонки MAE к диапазону нет.                                                                             |
| Smart Crop         | Частично                           | Обрезка с сохранением пропорций и ручным фокусом X/Y. Автоопределения объекта, лица и сопровождения объекта нет.                                                                                                                  |
| Color Adjustment   | Реализовано                        | Яркость, контраст, насыщенность, оттенок, виньетка. HDR PQ/HLG отклоняется с предложением SDR; автоматического HDR→SDR tone mapping нет.                                                                                          |

Комбинации фильтров, звука, временной шкалы и наложений проверяются на реальных синтетических MP4 в native FFmpeg и закреплённом FFmpeg.wasm.

## Анализ и проверка

| Требование                         | Статус                 | Фактическая реализация                                                                                                                                                                                                                                                                                  |
| ---------------------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Video Similarity Analyzer          | Реализован по выборке  | По умолчанию 5 пар, выбирается 3/5/7/9. Не анализирует все кадры полного ролика.                                                                                                                                                                                                                        |

Стандартная ширина анализа 160 px; это не метрика всех пикселей исходного разрешения.                                                                                                             |

| Покадровое сравнение               | Реализовано по выборке | Таблица времён, MAE, SSIM и pHash для каждой исследованной пары. Геометрия crop/flip и скорость выровнены. Добавленный хвост исключён.                                                                                                                                                                  |
| Карта различий                     | Реализовано            | Абсолютные различия центральной исследованной пары.                                                                                                                                                                                                                                                     |
| Quality Control                    | Частично               | Проверяются потоки, размеры, FPS, длительность, число кадров, наличие/длительность аудио, профиль MP4, полное декодирование, загрузка кадра и перемотка HTML video. SSIM <0.75 может запустить один повтор с ослаблением эффектов; <0.85 даёт предупреждение. Детектора всех визуальных артефактов нет. |
| Проверка метаданных после экспорта | Реализовано            | FFprobe после финальной очистки; оставшиеся поля и предупреждения включены в отчёт.                                                                                                                                                                                                                     |
| Проверка воспроизведения           | Частично               | Полное декодирование FFmpeg + чтение кадра и перемотка HTML video. Автоматическая проверка движения через play() и физические iPhone/Android не выполнены. ## 19.2–19.6

- Профиль MP4: H.264 / yuv420p / AAC-LC / 48 kHz / faststart, 30 FPS по умолчанию. Размер исходный или выбранная ширина с сохранением пропорций. WebM выбирается вручную.
- MP4-очистка стоит после кодирования, затем выполняются FFprobe и полное декодирование. Обязательные данные потоков сохраняются.
- MAE/SSIM — характеристики исследованных кадров, не вероятность распознавания дубликатов Instagram. Ни искусственных чисел, ни выдуманного «процента уникальности» нет.
- FFmpeg.wasm работает в Worker, метрики — в отдельном Worker. Параллельность ограничена одной задачей, ресурсы Worker освобождаются после каждого варианта.
- WebCodecs не реализован. Применён совместимый вариант FFmpeg.wasm.
- Прямого измерения свободной оперативной памяти нет. navigator.storage.estimate проверяет место хранилища, а не RAM. Есть ограничения размера, один Worker, освобождение ресурсов, обработка OOM и экономичный режим.
- Физические iPhone/Android и нагрузочный прогон 50 больших роликов не проверены. Планирование 50 независимых вариантов и ограничение очереди покрыты автоматическим тестом. Браузерная проверка выполнена на синтетических коротких файлах со звуком и без, с текстом/SRT, отменой/повтором, восстановлением и скачиванием.

## Удаление эталона

В Video Unique Studio эталон сравнения — исходное видео. Кнопка «Удалить эталон» удаляет его из IndexedDB и списка восстановления. Связанные незавершённые задачи отменяются; готовые файлы, метрики и отчёты сохраняются. Повтор без исходника блокируется. Операция удаления оригинала и обновления задач атомарна.

В отдельном Frame Studio эталон — профиль устройства. Для него показана явная кнопка удаления. Профиль удаляется из базы; исходный импорт помечается для очистки worker, обработанные медиафайлы остаются доступны.
