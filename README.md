# Video Unique Studio Advanced 2.0

Локальный редактор видео на Next.js и FFmpeg.wasm. Видео не отправляются на сервер. GitHub → Vercel; `npm ci`, `npm test`, `npm run build`.

## Реализовано

- Финальная очистка необязательных метаданных MP4 после кодирования. Блоки заменяются свободными атомами того же размера, чтобы сохранить смещения кадров и faststart. Технические поля потоков сохраняются. Оставшиеся поля выводятся в отчёте.
- Вариация длительности ±0,2–0,9 секунды; вариация кадров 6–27, по умолчанию 9–18. При совместном включении выбирается пересечение диапазонов. Положительный сдвиг добавляет неподвижный хвост и тишину, отрицательный обрезает конец. Базовое число кадров относится к исходнику, нормализованному под выбранные FPS и скорость.
- Обрезка с фокусом X/Y, масштаб, отражение, яркость/контраст/насыщенность/оттенок/зерно/виньетка. Сохранение пропорций и обработка ориентации.
- Adaptive Encoding: CRF по разрешению и битрейту на пиксель исходника. Для ручного режима CRF 18–28. MP4 H.264 High/yuv420p + AAC-LC 48 kHz + faststart. По умолчанию 30 FPS и исходное разрешение. WebM только по явному выбору.
- Звук: громкость, удаление, темп, нормализация loudnorm, плавное начало/окончание. Проверка наличия и длительности аудио после экспорта.
- Надписи, вступление из редактируемых шаблонов, генерация SRT из введённых строк, импорт SRT/WebVTT и реальное встраивание текста в кадры через PNG-слои. Это генератор таймингов текста, без распознавания речи или подключения LLM.
- Анализ реальных RGB24 кадров: MAE, локальный SSIM по яркости (8×8), DCT pHash 32×32 → 64 бита, расстояние Хэмминга, покадровые результаты, карта абсолютных различий. По умолчанию 5 пар, ширина 160 px. Сравнение по одинаковым номерам кадров нормализованной временной шкалы, с выровненными crop/flip/разрешением/скоростью. Добавленный хвост исключён. Диапазон MAE 7–8 — ориентир, не цель любой ценой и не показатель распознавания дубликатов.
- При SSIM < 0.75 возможен один повтор из оригинала с ослаблением цвета/зерна. Текстовые наложения отключают эту эвристику. SSIM < 0.85 отображает предупреждение для ручного просмотра.
- До 50 задач в очереди, 1–50 вариантов на исходник в пределах общего лимита. Независимые настройки, сохранение исходников/задач/Blob-результатов в IndexedDB, восстановление после закрытия, отмена и повтор ошибок. Только один FFmpeg Worker одновременно; Worker освобождается после каждой задачи. Метрики считаются отдельным короткоживущим Worker.
- Скачивание, просмотр, системное меню «Поделиться» для сохранения в Фото при поддержке браузером. CSV и JSON содержат настоящие результаты проверок; ZIP с CRC32, без одновременного чтения всех видео в массивы байтов.
- Успех только после проверки количества кадров, длительности, размеров, FPS, аудио, профиля MP4, полного декодирования и загрузки/перемотки результата в плеере браузера.

## Ограничения

До 10 минут и 250 МБ на исходник, до 4K. Экономичный режим автоматически включается на мобильных устройствах: до 100 МБ, новые задачи не шире 720 px. Браузер может исчерпать память раньше этих пределов. Обработка WebCodecs не используется: фактический совместимый движок — FFmpeg.wasm в Worker. Память WASM содержит только текущий исходник, результат и слои, а не всю партию.

ZIP до 1 ГБ; экономичный режим до 128 МБ. Необходим свободный объём хранилища браузера. Результаты можно скачать отдельно. Обработка прекращается при закрытии вкладки; очередь и исходники сохраняются для повторного запуска. Очистка данных сайта или вытеснение хранилища браузером удалит эти данные.

HDR PQ/HLG отклоняется с предложением предварительно экспортировать SDR, чтобы не получить неверные цвета. Не поддерживаемые браузером исходники отклоняются при загрузке. Smart Crop сохраняет геометрию и использует выбранный фокус; распознавания лиц нет. Проверка воспроизведения относится к текущему браузеру, а не всем физическим устройствам iPhone/Android/ПК.

Не гарантирует, что социальные платформы сочтут видео оригинальным или уберут метку ИИ.

## Проверки

`npm test`: реальные синтетические MP4 со звуком и без, различные временные сдвиги, совместные фильтры, наложения, AAC-LC, количество кадров, финальная очистка encoder/comment/title, faststart и полное декодирование; точные RGB-метрики; SRT/VTT; ZIP CRC32 и UTF-8; проверка импорта настроек. Отдельный тест запускает закреплённый FFmpeg.wasm core с реальными MP4: FFprobe JSON (включая код −1 при успехе), кодирование, звук, метрики, очистка и декодирование.

`npm test` также проверяет план из 50 независимых вариантов, защиту от повторяющихся имён и передачу буфера в Worker. GitHub Actions запускает тесты, TypeScript и сборку для main, advanced-v2 и pull request.

`npm run lint`: TypeScript. `npm run build`: production-сборка; prebuild копирует закреплённый @ffmpeg/core в public/ffmpeg. Внешняя CDN во время обработки не требуется.

## Проверка соответствия ТЗ

Полная матрица реализованных функций и ограничений: [docs/FEATURE_AUDIT.md](docs/FEATURE_AUDIT.md). WebCodecs, автоматическое распознавание объекта для кадрирования и прямое измерение свободной RAM не реализованы.

Кнопка «Удалить эталон» удаляет исходное видео из хранилища, предотвращает восстановление после перезагрузки и отменяет зависимые незавершённые задачи. Проверенные результаты и отчёты сохраняются; повтор без оригинала блокируется.

## Windows-программа

Нативная версия с установщиком, автоматическим поиском/загрузкой FFmpeg и FFprobe: [desktop/README.md](desktop/README.md). Среда запуска входит в установщик; отдельные Node.js/Python не нужны. Веб-версия сохраняет обработку FFmpeg.wasm.
