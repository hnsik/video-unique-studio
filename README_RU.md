# Video Downloader Studio 1.1 — Windows

## Что добавлено

- Instagram: фото, видео, Reels и смешанные карусели по ссылке на публикацию.
- Facebook: видео и Reels; фотографии по прямой ссылке открытого фото и фотоальбомы.
- Выбор «Всё», «Только фото», «Только видео».
- Пакет ссылок; ошибка одной загрузки не останавливает следующие.
- Кнопка остановки, журнал, число готовых файлов. Прогресс показывает долю обработанных ссылок, а не байтов.
- Существующие файлы не загружаются повторно. Они входят в число готовых файлов.
- Остальные видеосайты продолжают работать через yt-dlp.

## Запуск / обновление

1. Распакуйте архив в отдельную папку. Скачанные ранее материалы не нужно удалять.
2. Нужен Python 3.11+ с python.org (Python Launcher `py`).
3. Запустите `start_windows.bat`: зависимости установятся / обновятся автоматически, затем откроется приложение.
4. Для объединения раздельных видео- и аудиопотоков нужен FFmpeg в PATH. Фото не требуют FFmpeg.
5. Вставьте ссылки по одной в строке, выберите тип, папку и нажмите «Скачать».

## Какие ссылки использовать

Instagram: `https://www.instagram.com/p/КОД/`, `https://www.instagram.com/reel/КОД/`.
В режиме «Всё» карусель сохраняется отдельными файлами в подпапку Instagram.
В режиме «Фото» видео в карусели пропускаются. В режиме «Видео» загружаются доступные видео через yt-dlp.
Качество в настройках применяется к видеозагрузчику. Фото и видео внутри карусели в режиме «Всё» скачиваются в размере, предоставленном gallery-dl.

Facebook: `https://www.facebook.com/reel/ID`, ссылки videos/watch и fb.watch — для видео.
Для фото откройте его отдельно и скопируйте адрес вида `https://www.facebook.com/photo/?fbid=ID`.
Также поддерживаются ссылки на альбом `https://www.facebook.com/media/set/?set=…`.
Произвольные текстовые посты, короткие share-ссылки на фото, скачивание всего профиля и сбор всех вложений смешанного поста Facebook не реализованы.
В альбомах Facebook сохраняются фотографии, видео пропускаются.

## Вход / cookies

Если сайт запрашивает вход, выберите собственный локальный `cookies.txt` в формате Netscape.
Пароль в приложении не нужен. Cookies используются локальными загрузчиками для запросов к сервису.
Не отправляйте этот файл другим людям. Закрытая или удалённая публикация, истёкшие cookies,
ограничение запросов или изменения сайта могут помешать скачиванию.
При отсутствии файлов приложение показывает ошибку, даже если загрузчик завершился с кодом 0.
Если фото внутри Facebook-поста не определяется — используйте прямой адрес открытой фотографии.

## EXE

Этот архив содержит исходники и запуск через BAT, а не готовый установщик EXE.
Для сборки на Windows запустите `build_exe.bat`.
Файл появится в `dist/VideoDownloaderStudio.exe`; библиотеки включаются в сборку.
FFmpeg остаётся внешней зависимостью. Сборка с консолью нужна для вывода изолированных загрузчиков;
дочерние окна загрузки скрываются. Сборка Windows EXE в этой среде не проверена.

## Проверка

`py -m unittest -v test_backend test_worker`
Для интеграционного теста нужен FFmpeg. Проверены реальные локальные HTTP-загрузки изображения
и видео через gallery-dl / yt-dlp, фильтр фото, повторная загрузка, выбор обработчиков,
продолжение очереди после ошибки, остановка процесса и открытие интерфейса Qt.
Проверенные версии: gallery-dl 1.32.19, yt-dlp 2026.10.26.
Проверка Instagram/Facebook на живых публикациях с пользовательским входом не проводилась.

Загрузчики: https://github.com/yt-dlp/yt-dlp и https://github.com/mikf/gallery-dl
При изменениях сайтов перезапустите start_windows.bat для обновления зависимостей.
