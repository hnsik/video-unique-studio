# Проверки Video Unique Studio 3.0

Дата: 15 ноября 2026.

## Фактически выполнено в Linux

- 110 процедурных текстур: уникальные ID и 110 разных результатов в 128×128; воспроизводимость seed.
- Реальные синтетические MP4 и MOV; звук AAC и отсутствие аудио; пути с кириллицей.
- Удаление encoder из MP4 с сохранением заданных title/comment и последующим полным декодированием.
- Все 8 blend-режимов; многослойная композиция; начало/конец/fade слоёв; продление времени.
- Анимированный MOV qtrle с альфа-каналом; различие кадров анимации.
- 5 слоёв одновременно, повороты, pixel variation, замедление и метрики после кодирования.
- Сохранение собственной текстуры и чтение новым экземпляром сервиса.
- Отмена реального работающего FFmpeg.
- Сохранение отложенного начала аудиодорожки: тест с задержкой 0,4 с. Проверяется реальное положение начала звука в декодированном PCM.
- MOV/H.265, WebM/VP9, удаление двух кадров с конца, Gaussian-вариация и QC — успешно.
- Проверка идентичного видео: MAE 0, SSIM 1, pHash distance 0.
- Файлы большого размера и очередь 50: ниже.

## Windows

Первая сборка ветки studio-3-desktop: GitHub Actions run 43720902703 — установка NSIS EXE, запуск с включённым в установщик FFmpeg, повторный запуск, экспорт в прежнем редакторе и новый интерфейс (13 разделов, 5 слоёв, предпросмотр, экспорт, сохранение пресета) прошли. Получен и просмотрен скриншот установленной программы. Новые коммиты повторяют тот же процесс; точный итог смотрите в Actions и JSON-отчётах соответствующего релиза.

## Не проверено

- Физический ПК пользователя, отдельная Windows 10, разные AMD-драйверы.
- Многочасовые ролики, 50 файлов по 1 ГБ, HDR/10-bit, профессиональные MOV с необычной структурой.
- Все комбинации каждого ползунка и все сторонние кодеки.
- Цифровая подпись установщика отсутствует.

Локальный Chromium не запустился из-за ограничения создания сокетов. Проверка интерфейса выполнена установленным Electron на Windows runner; локальный неуспешный запуск не считается пройденным тестом.
