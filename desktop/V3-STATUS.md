# Video Unique Studio 3.0 — статус разработки

Это рабочая beta-версия, не завершённый релиз по всему ТЗ. Предыдущий редактор 2.2 сохранён и доступен по ссылке в левой панели. Идентификатор приложения и пользовательский профиль не меняются.

## Архитектурное решение

Сохранена существующая Electron/JavaScript-архитектура вместо переписывания на Python/PySide6. Обработка выполняется нативным FFmpeg в дочерних процессах. Слои не загружают всё видео в память. Процедурная генерация выполняется в worker_threads. Пакетная обработка последовательная. Сборка — electron-builder/NSIS, а не PyInstaller/Inno Setup. Пользователю Python и Node.js не нужны.

## Реализовано

- Отдельный русскоязычный редактор: 13 разделов, тёмная/светлая тема, изменяемая ширина инспектора, просмотр исходного и обработанного видео, разделитель сравнения, перемотка и шаг кадра.
- Прямой импорт видео с диска через FFprobe, большие файлы не копируются в память браузера.
- До 20 слоёв: background/overlay/foreground, восемь режимов смешивания, альфа, прозрачность, позиция, масштаб, поворот, симметричная обрезка, отражение, начало/конец, fade-in/out, loop, скорость и смещение видео-текстур. Порядок перетаскиванием, дублирование, блокировка, скрытие, группы со скрытием, дублированием и разгруппировкой.
- 110 процедурных текстур: 30 micro, 20 film, 20 light, 20 geometric, 20 backgrounds. Каталог, PNG-миниатюры и JSON-рецепты создаются в сборке и доступны офлайн. Разные seed/параметры и проверенные разные растровые результаты. Динамика генерируется в MOV qtrle с альфа-каналом.
- Импорт собственных изображений и видео в отдельные копии, категории, поиск, сортировка по названию, избранное, переименование, исключение из каталога без удаления оригиналов.
- Генератор текстур: выбор типа, разрешение, цвет, зерно, яркость, контраст, непрозрачность, seed, скорость, направление и параметры цикла. Серия из пяти текстур. PNG и анимированный MOV.
- Яркость, контраст, насыщенность, gamma, hue, температура, RGB-баланс, RGB-кривые, резкость, blur, композиция, обрезка, отражение; ограниченная вариация пикселей с синусоидальным, равномерным и Gaussian-распределениями с пространственной/временной корреляцией.
- Скорость, FPS, добавление/удаление кадров с конца, опциональная интерполяция движения, продление замедлением/последним кадром/переходом в чёрный, случайное +0,2–0,9 с.
- Метаданные FFprobe, удаление необязательных полей при перекодировании и финальная очистка encoder/compressorName без сдвига блоков MP4/MOV, title/comment, сохранение технических полей.
- Звук: громкость, mute, loudnorm, fades, atempo, AAC/Opus. Продление кадра сопровождается тишиной.
- Автопрофили с возможностью ручного редактирования.
- Очередь до 50 задач: прогресс, пауза между заданиями, отмена текущего, повтор ошибок, порядок, восстановление после перезапуска (с паузой), отчёт и лог, уникальные выходные имена. Seed и фактические параметры сохранены в JSON рядом с результатом.
- Пресеты JSON: сохранение/переименование/дублирование/применение/удаление/импорт/экспорт/по умолчанию; отсутствующие текстуры не подменяются.
- MP4/MOV H.264/H.265, WebM VP9, CRF, битрейт, CPU preset, аудиобитрейт, папка, имя. Проверка места, размеров, длительности, наличия аудио и полное декодирование после экспорта.
- Семь пар кадров по времени: MAE, локальный SSIM, DCT pHash (расстояние 0–64), PSNR, SHA-256 потоковым чтением. Среднее/min/max, покадровые значения. PSNR Infinity сериализуется JSON как null; у идентичных кадров MAE=0. Метрики — выборочная оценка в 128×72.

## Пока не соответствует полному ТЗ

- Обрезка пока симметричная. Положение/масштаб слоёв задаются в инспекторе; свободное редактирование непосредственно на кадре не реализовано.
- Произвольный монтаж отдельных кадров внутри ролика: сейчас добавление/удаление с конца, FPS/скорость; монтаж отрезков доступен в редакторе 2.2.
- Вариация пикселей ограничена до кодирования; сжатие, цветокоррекция и слои могут увеличить фактическое отклонение. Максимальное отклонение измеряется по семи уменьшенным контрольным кадрам, а не всем исходным пикселям.
- QC выполняет полное декодирование, blackdetect и поиск резких изменений средней яркости. Эти эвристики не отличают намеренные переходы/склейки от нежелательного мерцания: найденные участки требуют просмотра.
- Аудиосравнение: корреляция и MAE первых 20 секунд PCM 8 кГц с коррекцией скорости. Семантическое распознавание и проверка lip-sync не выполняются. HDR tone mapping не реализован.
- Аппаратное кодирование AMF и автообновление приложения.
- Нет отдельной очереди фонового анализа. Прокси создаётся по запросу для несовместимых форматов; автоматическое ограничение и очистка постоянного прокси-кэша ещё не реализованы.
- Предпросмотр — первые 5 секунд или весь ролик по переключателю, разрешение до 640 px. Это предварительное кодирование, не мгновенный 4K-рендер. Видеоплеер зависит от кодеков Chromium.
- Некоторые параметры генератора влияют только на соответствующие семейства текстур. «Animated Noise» — плавная процедурная модуляция зерна, не независимый случайный кадр каждый такт.
- Есть проверки установленного EXE на Windows runner; нет тестирования на физическом Ryzen 5 2600 / RX 570. Windows-инсталлятор считается проверенным только после успешного CI и появления EXE-артефакта.

## Как пользоваться

1. Добавить видео. Выбрать исходник в карточках под плеером.
2. Настроить профиль, цвет и время либо добавить слои из библиотеки.
3. Создать 5-секундный предпросмотр либо включить «Весь ролик». Сравнить рядом или разделителем.
4. В «Настройках» задать экспорт и выбрать папку.
5. Нажать «Экспортировать». Состояния — в «Очереди».
6. Готовый файл и JSON-отчёт сохраняются в выбранной папке. Оригиналы не перезаписываются.

Данные нового редактора сохраняются в подкаталоге studio3 пользовательского профиля Electron. Данные прежнего редактора остаются на прежнем месте. Перед переносом компьютера нужно копировать весь пользовательский профиль, а не только JSON-пресеты.

## Сборка

`npm ci`, `npm ci --prefix desktop`, `node desktop/scripts/ci-tools.cjs` (переменная VUS_BUNDLE_TOOLS=1), `npm run dist:win --prefix desktop`.
В Windows CI проверяются обе версии редактора. Установщик: `VideoUniqueStudio-3.0-Setup.exe`. Номер пакета 3.0.0-beta.1. Предрелиз не заменяет стабильный latest.
