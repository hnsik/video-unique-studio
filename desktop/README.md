# Video Unique Studio — Windows

Установщик Windows 10/11 x64 включает Electron (среду запуска), интерфейс приложения и нативный адаптер FFmpeg. Node.js и Python пользователю не нужны.

При первом запуске:

1. Проверяются ранее выбранная пара FFmpeg/FFprobe, кэш приложения, PATH и распространённые папки установки.
2. Совместимые компоненты версии 5+ с необходимыми кодировщиками/фильтрами используются повторно.
3. Если компоненты не найдены, скачивается закреплённый архив Gyan FFmpeg 9.0.2 по HTTPS. Перед распаковкой проверяется SHA-256 из `ffmpeg-manifest.json`.
4. Если интернета нет или загрузка не удалась, можно повторить попытку или выбрать установленный ffmpeg.exe, рядом с которым расположен ffprobe.exe.

Компоненты находятся в `%LOCALAPPDATA%\VideoUniqueStudio`; сам установщик устанавливает программу для текущего пользователя. Результаты скачивания сохраняются в `Downloads\Video Unique Studio`, доступна кнопка открытия папки. Очередь и результаты хранятся в IndexedDB приложения со стабильным origin `vus://studio`.

FFmpeg запускается напрямую отдельным процессом без командной оболочки. IPC ограничен локальными страницами, изолированными рабочими каталогами, разрешёнными аргументами и фильтрами. Node.js в интерфейсе выключен, включены sandbox/contextIsolation. Метрики считаются Worker, как в браузерной версии. Программа использует CPU-кодирование libx264; аппаратное GPU-кодирование в эту версию не добавлено.

## Разработка и сборка

```text
npm ci
npm ci --prefix desktop
npm test --prefix desktop
npm run dist:win --prefix desktop
```

Windows CI собирает NSIS, устанавливает настоящий EXE и запускает две проверки установленной программы (`--self-test`): с принудительной загрузкой компонентов и с повторным использованием. Проверка проходит через настоящий Chromium renderer → preload → нативный FFmpeg/FFprobe → метрики Worker → проверку воспроизведения → сохранение и удаление эталона.

Исходники FFmpeg и лицензия указаны в закреплённом манифесте и в каталоге компонентов. Electron/Chromium поставляются с их уведомлениями. Установщик не подписан коммерческим сертификатом; предупреждение Windows о неизвестном издателе возможно.
