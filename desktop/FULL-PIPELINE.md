# Video Unique Studio 3.2.0 — Full Pipeline

Оптимизация существующего приложения Electron/Node.js/FFmpeg, без замены проекта и без изменения фильтров итогового экспорта.

## Измерения

База: 3.1.0, commit `4b5e455a473f59bf785af2a3b4634c645e18eb07`. Новая версия: 3.2.0. Linux-контейнер, синтетический MP4 160×90, 12 FPS, 1 секунда, AAC. Один последовательный прогон каждого сценария; seed 12345, одинаковый исходник и параметры. Настройки результата совпали, кроме служебных UUID слоёв; framemd5 всех декодированных видеокадров итогового MP4 совпал полностью. Это проверка устранения повторных операций, а не прогноз скорости Ryzen 5 / RX570.

Native-вызовы учитывают основной Studio; собственный процесс предпросмотра в этот счётчик не входит. Миллисекундный повтор кадра не даёт устойчивого вывода о скорости — существующий кэш уже работал. Холодная обработка изменилась мало; основная выгода — повторное использование данных. Локальный подбор — явно обозначенный эвристический режим, НЕ ответ внешнего ИИ. Сетевые запросы в замер не включены.

Запуск: `node desktop/benchmarks/full-pipeline.cjs LABEL /absolute/path/to/desktop/lib /absolute/path/to/bench-root`. Используйте две отдельные версии lib и новые LABEL, один bench-root/исходник. Скрипт фиксирует seed только в собственном процессе. JSON содержит фактическое время и количество native-вызовов. Исторические измерения 19-секундного теста 3.0.2 → 3.1.0 находятся в `benchmarks/results/REPORT.md`; это не новый замер 3.2.0.

## Что изменено

- Анализ исходника кэшируется по пути, размеру, mtime и ctime; изменение прозрачности не вызывает повторное декодирование исходника. Изменение файла сбрасывает результат.
- Ограниченный LRU 16 МиБ / 100 записей сохраняет PCM аудио, результаты probe и измерения громкости. Финальная проверка экспорта по-прежнему выполняет свежий FFprobe.
- Texture Analyzer сохраняет контрольные экспорты и инвариантные сравнения. Ключ включает исходник, настройки, фрагмент, кадры, версии приложения/FFmpeg. Лимит 512 МиБ, очистка после задания. Отчёты имеют собственные копии изображений. Можно быстро проверить 110 текстур, затем полностью проверить отмеченные варианты.
- Быстрый кадр до 320 px и точный кадр в итоговом разрешении имеют общий движок эффектов, отдельную очередь, отмену устаревших работ, задержку обновления ползунков и ограниченный кэш. Старая обработанная картинка удаляется при изменении настроек. Точный PNG не заменяет проверку закодированного MP4.
- Сохранённые ИИ-предпросмотры восстанавливаются после перезапуска; удалённый кэш пересоздаётся. В интерфейсе показаны фактические слои и время этапов.
- Перед следующим заданием очереди проверяется доступность файлов и папки без второго тяжёлого экспорта. Сохраняются существующее восстановление очереди, один экспорт по умолчанию и отдельный предпросмотр.
- Диагностика измеряет анализ, быстрый/точный кадр при выбранном исходнике, сеть при настроенном провайдере, существующие прогоны CPU/GPU/фильтров/записи. Результаты хранятся в SQLite. Изолированные прогоны декодирования/фильтрации/кодирования не выдаются за слагаемые одного общего времени.

## ИИ-провайдеры и стоимость

Шесть адаптеров: Gemini, OpenAI Responses, Claude Messages, DeepSeek, Groq, OpenRouter. Нативный fetch повторно использует HTTP-пул; интерфейс не ждёт сеть синхронно. Каталог моделей кэшируется на час, ответы — только по включённой настройке на 10 минут. Кэш разделён по хешу аккаунта, ключи в нём не записываются.

Выберите провайдера, сохраните ключ, обновите каталог и выберите модель. Автопереключение по умолчанию выключено; разрешённые маршруты задаются явно `provider|model`. Платные запросы выключены до явного разрешения. Каталог не гарантирует наличие бесплатной квоты аккаунта. Диагностика по умолчанию запрашивает только каталог моделей; генерация для диагностики требует отдельной настройки.

404 обновляет каталог, затем допускает только разрешённый маршрут. 401/403 не повторяются. 429 учитывает Retry-After и блокирует преждевременные обращения к тому же аккаунту; ожидание свыше 15 секунд не держит интерфейс. 429/временные 5xx имеют не более двух повторов, общий бюджет — шесть генераций на видео, включая исправление и оценку плана. Тайм-аут получения заголовков 10 секунд, тела ответа 45 секунд. JSON проверяется локально; произвольные команды ИИ не исполняются. Локальный запасной подбор сопровождается уведомлением.

Источники форматов API: https://ai.google.dev/api/generate-content ; https://platform.openai.com/docs/api-reference/responses ; https://platform.claude.com/docs/en/api/messages ; https://api-docs.deepseek.com/api/create-chat-completion ; https://console.groq.com/docs/api-reference ; https://openrouter.ai/docs/api-reference/chat-completion .

## Проверки и ограничения

Локально: 19 целевых тестов прошли; после последних исправлений повторно прошли 3 новых теста. Проверены контракты шести провайдеров с HTTP-фикстурами, пагинация Gemini, 401/404/429, разрешения стоимости, бюджет запросов, кэш, изменение исходника, разрешение точного кадра и влияние текстуры. Существующие тесты проверяют все 110 текстур, режимы смешивания, порядок слоёв, альфа-канал, анимацию, метрики, отмену и сохранение оригиналов.

Реальные аккаунты и квоты шести ИИ-провайдеров НЕ проверены: ключи пользователя отсутствуют. Физические Ryzen 5 2600 / RX570 и драйвер AMD недоступны. Для 3.2.0 не повторены нагрузочные сценарии 1 ГБ/50 файлов и полная серия 19-секундных сценариев. VMAF вычисляется только при наличии libvmaf; отсутствие показывается, не заменяется вымышленным результатом. Полный тест текстуры включает реальный контрольный экспорт и выбранные кадры; покадровый полный анализ видео выбирается отдельно. Нет гарантии обхода распознавания платформ.

## Установка и данные

Установщик сохраняет appId и пользовательские папки; удалять старую версию перед обновлением не требуется. При запуске 3.2.0 создаются отдельные резервные копии state.json и зашифрованного ai-keys.json, исходные файлы не удаляются. Сборка и проверка установки поверх 3.1.0 выполняются workflow Windows installer; окончательный статус подтверждается результатом CI, а не этим описанием.
