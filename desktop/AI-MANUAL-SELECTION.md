# Ручной выбор ИИ-варианта — 3.2.3

## Использование

1. Выполните подбор ИИ и раскройте «Варианты: измерения, причины и предпросмотр».
2. Посмотрите контрольный фрагмент.
3. Нажмите «Выбрать этот вариант», затем «Применить с предупреждением».
4. Программа сохранит именно эти параметры, seed и слои, без дополнительного ослабления и без нового API-запроса. В редакторе создаётся обычный предпросмотр до 5 секунд.
5. Проверьте до/после и нажмите «Экспортировать».

Предупреждения SSIM, MAE и недостаточной выраженности не блокируют ручной выбор. Ошибки обработки, недостоверные измерения, новые чёрные интервалы, дополнительные скачки яркости и риск перегрузки звука блокируют его. Backend повторно проверяет статус задания, принадлежность варианта исходнику, разрешённые предупреждения, подтверждение пользователя, наличие исходника/текстур и видеопоток контрольного фрагмента. Настройки из запроса UI не принимаются — используются параметры проверенного кандидата.

Кнопка «Последние варианты» в диалоге запуска ИИ открывает результаты текущего сеанса. После обновления приложения подбор нужно выполнить заново: отклонённые варианты прошлой версии не сохранялись между сеансами. Уже применённый ручной выбор сохраняется после перезапуска.

Ручной выбор не означает успешное прохождение автоматических порогов. Признак manualSelection, selectedCandidateId и принятые предупреждения записываются в результат. Полный ролик автоматически не анализируется при выборе; обычные проверки экспорта сохраняются. API-ключи, модели, пресеты и оригиналы не меняются.

## Тестирование

Локально: 9 AI-тестов прошли, включая реальную обработку FFmpeg, принудительное отклонение по SSIM, отказ без подтверждения, неизвестный кандидат, блокировку технических ошибок, сохранение точных параметров, перезапуск состояния, экспорт и неизменность исходника.

Windows CI дополнительно запускает полный набор тестов, устанавливает приложение поверх 3.2.2 и проверяет кнопку ручного выбора через интерфейс. Фактические результаты сборки следует проверять в журнале соответствующего workflow; сам исходный код не подтверждает успех сборки.

Не выполнялись платные API-запросы или проверка исходного ролика пользователя.
