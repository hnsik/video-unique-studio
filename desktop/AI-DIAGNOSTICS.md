# ИИ-диагностика — 3.2.1

## Что проверено реально

15 ноября 2026 выполнены настоящие GET-запросы официальных каталогов **без ключей**, из среды разработки. Результаты не показывают доступность моделей для пользовательского аккаунта и не означают успешную генерацию.

| Провайдер | GET-каталог без ключа | Авторизованная генерация |
|---|---|---|
| Gemini | HTTP 403, PERMISSION_DENIED | Не проверена |
| OpenAI | HTTP 401, отсутствует Bearer | Не проверена |
| Claude | HTTP 401, требуется x-api-key | Не проверена |
| DeepSeek | HTTP 401, authentication_error | Не проверена |
| Groq | HTTP 403, error code 1010 | Не проверена |
| OpenRouter | HTTP 200, 467 моделей | Не проверена |

Ключи хранятся на ПК пользователя под Windows DPAPI и недоступны среде разработки. API-ключи не запрашивались для передачи в чат. Список действительно проверенных генерацией моделей пока пуст. Публичный снимок OpenRouter: `benchmarks/results/ai-public-catalog.json`; исходные HTTP-результаты: `benchmarks/results/ai-reachability.json`. OpenRouter /models публичный: успешный ответ не проверяет ключ. Groq 403 без ключа из этой среды не доказывает ошибку пользовательского ключа или недоступность сервиса на пользовательском ПК.

## Причина сообщения Gemini

На предоставленных скриншотах: 49 моделей из кэша, выбран gemini-2.5-flash-lite, затем фраза «Модель существует, но маршрут генерации недоступен». В версии 3.2.0 эта фраза создавалась после HTTP 404 и проверки наличия ID в каталоге. Исходное сообщение API при этом терялось. Поэтому установлено расхождение между каталогом и реальным запросом, но точная причина 404 (права, устаревшая запись, метод/модель) не доказана. Подменять её предположением об ошибочном ключе нельзя.

Исправлено сохранение безопасной причины API, HTTP-статуса, модели и маршрута; принудительное обновление при 404 больше не затирает исходную ошибку. Проверяются методы, возможности и состояние модели. После обновления выполните явный тест Gemini и сохраните отчёт: он даст недостающую причину на вашем аккаунте.

## Интерфейс

1. Настройки → Настройки ИИ → «Проверить все ИИ».
2. Получите независимые колонки: каталог, совместимость модели, генерация, локальный обработчик. Каталог и модель проверяются без генерации.
3. Кнопки «Модели» и «Обновить каталог» показывают API/кэш и дату успешного получения. Несовместимые варианты исключены из подсказок; сохранённый ID не стирается даже при исчезновении из каталога. Пустой каталог показан явно. Последняя успешная дата сохраняется и показывается при ошибке обновления.
4. «Тест генерации · <провайдер>» требует отдельного системного подтверждения. Только выбранный провайдер/модель, один запрос, максимум 2000 выходных токенов, без повторов и переключения. Разрешение биллинга в настройках остаётся обязательным для платных маршрутов. Другие кнопки подключения и диагностики производительности больше не запускают генерацию, даже если в старых настройках был allowPaidDiagnostics.
5. Проверяется не только JSON: три варианта проходят обычный cleanPlan, первый применяется обработчиком к синтетическому 64×64 ролику с FFmpeg/FFprobe. Пользовательские видео не отправляются и не изменяются. Ошибка обработки имеет отдельный статус, не скрывает успешный ответ модели.
6. Диагностику можно отменить и сохранить в JSON; закрытие окна отменяет текущую диагностику. Ключи, заголовки и параметры авторизации не включаются в отчёт.

## Каталоги и ограничения определения возможностей

| Провайдер | Каталог | Генерация | Основание совместимости |
|---|---|---|---|
| Gemini | GET generativelanguage.googleapis.com/v1beta/models | POST /v1beta/models/{id}:generateContent | supportedGenerationMethods; специализированные TTS/live/image/embedding исключены |
| OpenAI | GET api.openai.com/v1/models | POST /v1/responses | /models не содержит полной матрицы методов; документированные текстовые семейства, неизвестные требуют реального теста |
| Claude | GET api.anthropic.com/v1/models | POST /v1/messages | capabilities/lifecycle, пагинация; retired исключены; версия 2026-10-21 |
| DeepSeek | GET api.deepseek.com/models | POST /chat/completions | доступные input/output modalities и ограничения; при отсутствии данных статус «Не проверено» |
| Groq | GET api.groq.com/openai/v1/models | POST /openai/v1/chat/completions | active + документированные текстовые семейства; Whisper/TTS/guard исключены |
| OpenRouter | GET openrouter.ai/api/v1/models | POST /api/v1/chat/completions | architecture/output_modalities, endpoints, supported_parameters, pricing |

Названия семейств помогают предварительно отсеять заведомо неподходящие модели, но не подтверждают права ключа и поддержку JSON. У Gemini наличие generateContent не является обещанием поддержки JSON у всех специализированных моделей. При неизвестных возможностях допустим ручной тест; автоматический выбор ограничен моделями с положительным предварительным признаком совместимости, реально присутствующими в каталоге.

Официальные источники: https://ai.google.dev/api/models ; https://developers.openai.com/api/reference/responses/overview ; https://platform.claude.com/docs/en/api/models/list ; https://platform.claude.com/docs/en/api/versioning ; https://api-docs.deepseek.com/api/list-models/ ; https://api-docs.deepseek.com/api/create-chat-completion/ ; https://console.groq.com/docs/api-reference ; https://openrouter.ai/docs/api/api-reference/models/get-models .

## Переключение, ошибки и нагрузка

Автоподбор модели включается явно. Он выбирает совместимую модель из свежего/TTL-каталога выбранного провайдера, с отдельной проверкой права на биллинг. Между провайдерами используются только перечисленные разрешённые provider|model; автоматическая замена модели другого провайдера не производится. 401/403 исключают остальные попытки с тем же ключом в текущем подборе. 429 учитывает Retry-After, включая запросы каталога. 404 обновляет каталог и сохраняет первичную ошибку. Повторы только для 429/временных 5xx, общий бюджет генерации прежний. После исчерпания API локальный подбор допускается только по соответствующей настройке и помечается как локальный.

До двух одновременных сетевых загрузок каталогов, повторные запросы одного каталога объединены. Отмена одного подписчика не прерывает другого; при отмене всех прерывается HTTP-запрос. Кэш один час, с отдельной записью даты последнего успеха. Старые модели/ключи/настройки не удаляются. Соединения использует повторно штатный fetch. Тайм-аут заголовков 10 с, тела 45 с, ограничены размеры ответов.

HTTP 400/401/402/403/404/429/5xx: провайдер, ID, статус, тип, очищенное сообщение, маршрут без query/секретов и рекомендация. Из тела берётся только сообщение/тип ошибки; ключи и токены редактируются. API-текст отображается через textContent, не HTML.
